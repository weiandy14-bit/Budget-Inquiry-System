# 機電工程預算編制系統使用說明

## 開始使用

1. 在案件清單選擇既有案件，或輸入案件編號與名稱建立新案。
2. 先到「參數設定」確認綜合日工價及各項參數。
3. 到「系統明細」選擇大系統與子系統，輸入工項及數量。
4. 到「合理性檢核」處理缺價、異常價格及同碼不同價等提醒。
5. 按「儲存」將案件寫入目前瀏覽器。
6. 重要修改後按「匯出完整備份」，保存下載的 JSON 檔。

系統會依「數量 × 工率 × 日工價」即時計算工資。工率檔位預設跟隨系統設定，只有指定明細列需要例外時
才使用手動覆寫。

## 資料存在哪裡

案件與自訂主檔存在目前瀏覽器 profile 的 IndexedDB：

- 不會自動上傳 GitHub、雲端或其他電腦。
- Chrome 與 Edge 不共用資料；同一瀏覽器的不同 profile 也不共用。
- 清除網站資料、刪除瀏覽器 profile、電腦故障或更換電腦，都可能失去案件。
- 應用程式更新通常會保留同一網站來源的 IndexedDB，但更新前仍應先備份。

## 完整備份

- 系統會在案件頂端及案件清單顯示最後備份時間。
- 從未備份或超過 7 天會顯示提醒。
- 建議至少每 7 天、重要修改後、清除瀏覽器資料前及應用程式更新前備份。
- 備份 JSON 包含案件及該案件引用的自訂工項；每個重要案件都應各自保存一份。

最後備份時間只是目前瀏覽器的提醒紀錄，不會寫入案件，也不能代替實際 JSON 檔。下載後請確認檔案確實
存在，並保存到受管理的專案資料夾或公司備份位置。

## 還原或搬移案件

1. 在案件清單按「匯入案件備份（.json）」。
2. 選擇先前匯出的 JSON 檔。
3. 檢查畫面顯示的備份版本、案件及自訂工項新增／相同／衝突數量。
4. 自訂工項衝突時，只有確認後才會用備份內容覆寫本機同碼資料。
5. 匯入後核對工程總價、日工價及主要系統小計。

## 刪除案件

刪除前會顯示本機最後備份狀態。刪除沒有回收區，也無法靠里程碑紀錄還原；沒有完整 JSON 備份時，
不應刪除仍需使用的案件。

## 無法開啟本機資料時

1. 先按「重試」，不要清除瀏覽器資料。
2. 若其他分頁或舊版本仍可開啟，先逐案匯出完整備份。
3. 關閉其他仍開啟本系統的舊分頁，再回來重試。
4. 只有已有備份或確定放棄資料時，才按「重建本機資料庫（清除資料）」。
5. 重建後從 JSON 備份逐案匯回，並核對總價。

若備份匯入失敗，依畫面指出的欄位路徑修正來源檔；不要直接刪除欄位或降低備份版本來強行匯入。
